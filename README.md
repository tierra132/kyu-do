# 弓道譚 — 一射の稽古（試作版）

HTML Canvas / JavaScript 製の軽量ブラウザゲームです。GitHub Pages で公開できます。

## 操作
- 「稽古を始める」
- 引き分け：画面を押して下へスライド。十分な距離まで引くと会へ移行
- 会：的・矢・弓の籐付近と照準を見ながらドラッグして狙いを調整
- 「離れを行う」で射る
- 的中・外れ、中心からのずれを確認し「もう一射」
- センサーは開始画面から有効化可能。使えない場合はドラッグ操作を利用

## GitHub Pages
`index.html` と `README.md` をリポジトリ直下に置き、Settings → Pages → Deploy from a branch → `main` / `/(root)` を設定します。

## 制約
キャラクター、道場、弓、的は Canvas によるスタイライズ表現です。実際の弓道の射法や矢の空力を厳密に再現する完成版ではなく、操作・画面遷移を検証する試作です。
