# 弓道ゲーム 試作版 ver.0.1

## ローカルで試す
`index.html` をブラウザで開いてください。センサーの利用はブラウザや端末の制約により、HTTPS環境での確認を推奨します。

## GitHub Pagesで公開する
1. GitHubで新しいリポジトリを作成します。
2. このフォルダ内の `index.html` と `README.md` をリポジトリ直下にアップロードします。
3. リポジトリの Settings → Pages を開きます。
4. Build and deployment の Source を `Deploy from a branch` にし、公開するブランチ（通常は `main`）とフォルダ `/ (root)` を選択して保存します。
5. 表示されたURLからアクセスします。

## 操作
- 引き分け：画面を押して下方向へ引きます。十分な距離まで引くと会に移行します。
- 会：画面をドラッグして照準を調整し、指を離すと射ます。
- 傾きセンサー：対応するiPhone/Safariでは、開始画面または会の画面から許可できます。動作しない場合は画面操作を使ってください。
- 結果画面：「もう一射」で再挑戦します。

## 注意
これは操作感を確認するための初期プロトタイプです。キャラクター・弓・的はCanvasによる簡易描画で、実際の弓道の射法・矢の物理を厳密に再現するものではありません。
