# 弓道譚 — 一射の稽古（試作）

スマートフォン・PCのブラウザで動作する、弓道の操作感を検討するための試作です。

## 操作
1. 「稽古を始める」を押すと、打起しの姿勢から始まります。
2. 画面を押したまま下へドラッグして引き分けます。バーは最大位置が決まっており、終盤ほど進み方が鈍くなる非線形カーブです。
3. 引き分けの終端で、指を離さず会へ移行します。
4. 会で指を小さく動かして狙いを調整します。指を離すと離れ・発射になります。
5. 的中判定と矢所を確認し、「もう一射」で繰り返せます。

## GitHub Pagesへの公開
`index.html` をリポジトリのルートに置き、GitHub の Settings → Pages で公開元ブランチとルートフォルダを指定してください。ビルド工程は不要です。

## 現時点の限界
- 図形ベースの2D表現であり、人体・弓具の正確な3D運動や流派ごとの射法を再現したものではありません。
- 抵抗感は画面上の進捗カーブで表現します。端末の画面に物理的な力は発生しません。
- 的中判定は操作確認用の簡易モデルです。実射の矢道・弓力・矢の物理を計算していません。
- このファイルはブラウザ上の操作試作です。実機の複数サイズで操作感を確認し、弓道経験者の監修を得てから本格版へ進めてください。
